# v1.2.0 · 多平台音乐与 HiFiTi 原生渠道

## 下载与使用

- Windows x64：下载 `MusicDownloaderWeb.exe`，或下载带说明／许可证的 `MusicDownloaderWeb-v1.2.0-Windows-x64.zip`。
- 放入独立可写文件夹，双击 EXE，等待控制台自检及浏览器打开。无需安装 Python、Node.js 或 FFmpeg。
- 使用自己的账号；默认本机 `127.0.0.1:8899`，端口占用时以控制台实际地址为准。保持控制台开启。
- 发布包无开发者账号、Cookie、Token、缓存、下载内容或已安装 AI 目录。请只转发原始发布文件，不转发使用后的整个目录。
- EXE 未做商业代码签名，Windows 可能提示未知发布者；可核对本 Release 的 `SHA256SUMS.txt`。不要求关闭安全软件。

## 本次更新

- 加入独立网易云搜索、扫码登录、按账号权益下载、TXT／LRC 歌词、翻译和罗马音选项。
- 仅在合法下载实际返回 NCM 时处理副本；内置校验过的官方工具，完整验证输出，保留原始 NCM，转换失败独立提示。
- 加入咪咕独立搜索、官方二维码登录、原文歌词和实际下载事务通道；不以试听／播放链接替代下载权限。
- 加入 **HiFiTi渠道** 原生搜索、分页、帖子详情、账号登录／注册；不再内嵌整站。账号可见链接与明确提取码整理为可复制资源卡片，详情在点击的帖子下方展开。
- HiFiTi 登录验证成功后关闭弹窗，顶部和论坛入口显示账号状态；保留密码清空、CSRF、owner 隔离及迟到响应保护。
- 宽屏四栏依次为搜索结果、mflac 转换、已下载文件、人声分离；中屏两栏、窄屏单栏。
- 汇总 AI 组件下载加速、断点续传、可用源选择与安装反馈改进。AI 为可选独立下载，约 749 MB，不塞入 EXE。
- 增加版本资源、可复现打包入口、嵌入资源检查、Pillow／新渠道资源启动检查与第三方许可证。

## 诚实边界与已知限制

- 本次不是另一台干净电脑／虚拟机测试；不保证所有系统、网络、代理、防火墙或平台账户组合可用。
- 本次未扫码确认登录、未真实注册 HiFiTi 账号、未测试会员全曲库下载、未重新下载／安装约 749 MB AI。历史源码验证过的账号能力不等于本次对所有 EXE 在线权限重新验证。
- 网易云、QQ、咪咕登录相互独立；登录不保证版权、会员或下载权限。HiFiTi 的官网接受注册也不等于激活或登录。
- **古巨基／周深《泪桥》（《声生不息.家年华》第12期）此前官方下载事务仍返回“查询歌曲价格失败”，尚未成功下载，不能保证登录解决。** 不替换成其他录音。
- HiFiTi 不自动回复、扣点、购买或绕过隐藏内容；外部网盘链接不代表已验证文件可下载，也不会自动下载到本地列表。部分帖子站内标签仍可能被识别成链接卡片，需核对资源域名。
- 平台结构和接口可能变化；验证码、安全检查或权限拒绝时停止，不绕过。
- AI 下载速度随网络变化；本版不会自动安装可选 AI。
- 仅服务本机，不应直接把 8899／9999 对局域网或公网开放。
